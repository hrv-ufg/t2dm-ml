# t2dm-ml

# Multimodal Machine Learning for Type 2 Diabetes Mellitus Detection

This repository contains the source code used in the study:

**Multimodal Machine Learning for Type 2 Diabetes Mellitus Detection**

The study investigates the use of clinical and heart rate variability (HRV) features, including linear and nonlinear measures, for Type 2 Diabetes Mellitus (T2DM) detection using machine learning.

## Features

The experiments evaluate two feature sets:

- **FS1:** Clinical + linear HRV features
- **FS2:** Clinical + linear + nonlinear HRV features

The evaluated classifiers are:

- L2 Logistic Regression
- Gaussian Naive Bayes
- Support Vector Machine
- Multilayer Perceptron

## Dataset

The dataset used in this study is **not publicly available due to ethical and privacy restrictions**. Access may be considered upon reasonable request and subject to institutional approval.

## Reproducibility

The code implements the preprocessing, feature selection, model training, cross-validation, and performance evaluation procedures described in the paper.
